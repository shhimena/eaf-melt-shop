# EAF Melt Shop KPIs

A single-page website for the EAF Melt Shop: chemistry dispositions by crew, out-of-spec chemistry, furnace and caster operator spec performance, and billet production vs plan.

Open `index.html` in a browser, or view it on GitHub Pages. The data inside is a saved copy of the monthly Chemistry and Billet Excel reports (May–October 2026). The **Update data** button can preview newer Excel reports in your own browser; to change what everyone sees, replace `index.html` with a newer copy.
